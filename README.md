# BatteryTray

Windows tray app that shows wireless peripheral battery levels.

**v1.0.1** — created by Marco

## Supported

- BLE devices with a standard battery service
- Logitech G502 X PLUS (needs G Hub)
- Scyrox V8
- HyperX Cloud II Wireless (2.4G dongle; not the wired-only Cloud II)

Barracuda X 2.4 and other brands are not supported yet.

## Run

```
python -m pip install -r requirements.txt
python main.py
```

Right-click a tray icon for **Refresh now**, **Start with Windows**, **About**, or **Quit**.
